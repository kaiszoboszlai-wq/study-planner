# 長期学習計画

ユーザー提供「テキスト 8.txt」の方針に基づく学習計画ページ。

- 試験名、文章で宣言する目標、試験日、計画期間を4問の全画面設定で保存する。
- 保存済み参考書ルートを科目ごとにカレンダーへ配置する。追加時は科目内で期間を均等に分け、ルートの教材順を保持する。
- 教材を押すと開始日・終了日・完了を編集できる。両端のハンドルをドラッグしても1日単位で調整できる。キーボードではハンドルまたは教材から期間入力を開ける。
- カレンダーは月の見出し、科目カラー、今日の線、科目フィルターを持つ。スマホではこの領域だけ横にスクロールする。
- 「今月の目標」は置かない。「今取り組む教材」は開始済みかつ未完了の教材。期限超過も見直せるよう残し、完了は除外する。端末のローカル日付に従って日をまたいだときに更新する。
- 目標編集ボタンは表示しない。保存したルートを削除しても、計画中の教材は保持する。

`state.longTermPlan` に保存し、既存のアカウント別保存・同期を使う。目標と各教材を3方向でマージし、別々の教材への変更を維持する。古いクライアントが新フィールドを送信しない場合もローカルの長期計画を消さない。フォーム送信時にはアカウント・認証世代・計画スナップショットを照合する。保存失敗は計画のローカル状態を戻す。

教材に学習時間を割り当てず、既存の週間プラン・タイマー・学習記録は変更しない。週間プランの条件設定へ保存ルートの参照欄は復活させない。

実装：`assets/long-term-plan.js`、`assets/long-term-plan-ui.js`、`assets/long-term-plan.css`。

検証：`node tests/long-term-plan.cjs`、`node tests/long-term-plan.browser.cjs`。日付の境界、期間制約、科目内の順番、二重追加、期限超過・完了、独立編集の同期、旧クライアント、4問設定・試験名検索・文章の目標、日付編集・ドラッグ、再読み込み、320/390/768px幅、アカウント切り替えを確認する。Firebaseへの実接続による2端末同時編集は未検証。

試験名は `goal.examName` に保存します。既存の `goal.exam` は試験日のまま維持します。旧計画は試験未設定として表示し、従来の得点・得点率も保持します。

文章の目標は `goal.declaration`（1〜200文字）に保存する。数値の目標の旧データも引き続き読める。ロードマップの見出し・科目フィルター・カレンダーを1枚のカードにまとめる。

参考書ルートをまだ追加していない場合も、設定した計画期間の月見出し・日付目盛り・今日の線を持つ空のカレンダーをロードマップカード内に表示する。

ロードマップは約9か月分が表示領域に収まる日付スケールを使う。9か月より短い計画は全期間を表示する。科目見出しの幅も画面に合わせ、画面幅の変更時に再計算する。縮小で教材名が収まらない場合も、クリックして開く編集画面とタイトル属性から名前・期間を確認できる。

ルート追加から、条件に基づく自動作成または登録教材の検索による手動作成を選べる。手動ルートは選択順で保存してから計画に追加する。教材を今月の初日まで遡って調整でき、計画開始日より前に広げた場合は開始日も合わせて更新する。
