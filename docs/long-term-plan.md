# 長期学習計画

ユーザー提供「テキスト 8.txt」の方針に基づく学習計画ページ。

- 目標点／得点率、試験日、計画期間を3問の全画面設定で保存する。
- 保存済み参考書ルートを科目ごとにカレンダーへ配置する。追加時は科目内で期間を均等に分け、ルートの教材順を保持する。
- 教材を押すと開始日・終了日・完了を編集できる。両端のハンドルをドラッグしても1日単位で調整できる。キーボードではハンドルまたは教材から期間入力を開ける。
- カレンダーは月の見出し、科目カラー、今日の線、科目フィルターを持つ。スマホではこの領域だけ横にスクロールする。
- 「今月の目標」は置かない。「今取り組む教材」は開始済みかつ未完了の教材。期限超過も見直せるよう残し、完了は除外する。端末のローカル日付に従って日をまたいだときに更新する。
- 目標期間を変更すると教材日付を新期間内に収める。既存教材は消さない。保存したルートを削除しても、計画中の教材は保持する。

`state.longTermPlan` に保存し、既存のアカウント別保存・同期を使う。目標と各教材を3方向でマージし、別々の教材への変更を維持する。古いクライアントが新フィールドを送信しない場合もローカルの長期計画を消さない。フォーム送信時にはアカウント・認証世代・計画スナップショットを照合する。保存失敗は計画のローカル状態を戻す。

教材に学習時間を割り当てず、既存の週間プラン・タイマー・学習記録は変更しない。週間プランの条件設定へ保存ルートの参照欄は復活させない。

実装：`assets/long-term-plan.js`、`assets/long-term-plan-ui.js`、`assets/long-term-plan.css`。

検証：`node tests/long-term-plan.cjs`、`node tests/long-term-plan.browser.cjs`。日付の境界、期間制約、科目内の順番、二重追加、期限超過・完了、独立編集の同期、旧クライアント、3問設定、日付編集・ドラッグ、再読み込み、320/390/768px幅、アカウント切り替えを確認する。Firebaseへの実接続による2端末同時編集は未検証。
