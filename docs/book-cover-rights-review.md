# 参考書の書影：利用条件の確認結果

確認日：2026年10月26日。対象は、この学習プランナーでの教材紹介、画像取得・保存、Web表示。

## 調査範囲と読み方

- 登録済み10,343冊について、出版社名の表記499件をCSVに整理しました。旧社名・表記違いを含むため、499社という意味ではありません。
- 提供元・主要出版社について23件の条件記録を作成しました。取得できなかった公式ページと、まだ個別調査していない出版社は明確に区別しています。
- 24件の出版社表記に条件記録を紐付けています。これらが扱う4,937冊すべてに転載許可がある、という意味ではありません。全499件の出版社規約を読み終えたとはしていません。
- 出版社サイトから直接取得する条件、openBDが提供するデータの条件、版元ドットコムの個別書籍の利用表示は、取得経路ごとに判断します。
- 「利用可否不明」「規約取得不可」「未調査」を、利用禁止・許諾済みのどちらにも置き換えません。

## 今表示している書影の追加確認

追加前の163冊は、openBD APIの提供データとして取得したものです。この163件について、版元ドットコム上の書籍別表示も追加で照合しました。

- 版元ドットコムに明示の「利用可」があったもの：109件。
- 同サイト上で「利用可否不明」だったもの：54件。
- この54件は、版元ドットコムのページから直接取得する経路では未承諾です。openBD API経由の利用条件と同一視して、禁止・許諾済みを断定することはしません。

既存の取得ファイルはISBN・書名照合、取得元・確認日・SHA-256・有効期限の記録を持ちます。TAC以外の新たな出版社サイトを無条件に使う処理は入れていません。TACの追加分には書籍紹介に限る条件を適用しています。

## 今回の追加結果

- openBD：163冊。
- TAC公式ストア：187冊をISBN・書名・紹介条件に従って追加。正確な商品ページリンクを表紙の横へ表示します。
- 合計350冊。そのうち最新版ポリシーに合うものは349冊、現在アプリで対応している試験の候補となるものは219冊です。
- TACの候補331件のうち、検索で見つからなかった53件、照合できなかった89件、再試行後も通信で取得できなかった2件は追加していません。これらを著作権上利用禁止と断定していません。

## 今後追加できる経路と必要な準備

1. **TACの紹介用途**：公式ガイドラインの条件に合わせ、正確な商品ページリンク、または出版社・書名・著者名を添える必要があります。許諾不要は紹介目的の条件であり、本文や講義教材を投稿できるという意味ではありません。商品とのISBN照合ができていない画像は追加しません。
2. **版元ドットコム**：個別書籍に「利用可」があることを確認した画像のみ、同サイトからの取得候補にできます。
3. **楽天の公式API**：開発者登録、App ID、商品へのリンク、クレジット、情報共有・環境等の規約条件を満たしてから使う経路です。アカウントは作成していません。
4. **Google Books API**：API規約・追加規約・ブランド規定があり、今回の「静的画像を恒久保存する」方式へそのまま流用しません。
5. **要申請の出版社**：申請者の氏名・利用媒体等を含む出版社への送信は行っていません。公開情報の調査のみです。
