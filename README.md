# 学習プランナー

静的な画面と教材データで動く学習プランナーです。参考書ルートの作成にAIや有料APIは使いません。アカウント保存・同期は既存のFirebase設定を使用します。

GitHub Pages等の静的ホスティングでルート作成を利用できます。表紙の取得APIを使う場合はVercel等に配置してください。AIのAPIキーは不要です。

### 参考書ルート（実行時AIなし）

カタログは書誌確認済み10,343冊です（拡張前2,167冊）。2026年時点の版判定を通る10,009冊のうち、現在の対応試験に属するデータは8,342冊です。別途残している未確認候補77冊は提案に使いません。書誌確認は販売状況の確認ではありません。

参考書データは `assets/book-catalog.json` に事前収録し、`assets/book-route-engine.js` がブラウザ内で条件に合うルートを組み立てます。参考書ルート作成にAI・有料API・APIキーは使いません。学習条件をAIへ送信しません。教材JSONの初回読込後は、表紙なしでもルートを作成・保存できます。

入力：試験の種類、試験名・級、教科・単元、試験日、現在の実力・目標スコア、所持教材。試験を選んだ直後にカレンダーで試験日を選び、残り日数を自動計算します。苦手分野・優先分野・おおよその残り期間の質問はありません。目標は、入試の得点率、TOEICの点数、英検のCSE合格基準、資格の採点方式に応じた選択肢です。所持教材は教科・試験・級で絞り込みます。理解度も試験別に分岐し、英検は受験級と学習分野、TOEIC・IELTS・TOEFLは現在のスコア帯、簿記・IT・法律などの資格は固有の出題内容に沿って選択します。英検の正答割合はCSEスコアや合否とは別の理解度の目安です。

選定：試験・級・教科・単元を絞り、編集した難易度や分野タグと所持教材で順位付けします。「所持教材優先」「基礎重視」「教材を絞る案」を比較し、同じ組み合わせは除外します。十分な候補がないときは1案になり、対応データがないときは提案しません。期間が短い場合は、必要な章だけに取り組む案として明示します。教材ごとの日数配分や1日あたりの学習時間は計算・表示しません。

国立国会図書館サーチの書誌と書名・巻番号・出版社・ISBNを照合した教材だけを提案対象にします。書誌記載価格は当該版の記録であり、最新の税込定価を保証しません。登録済みの書誌価格はその旨を添えて教材タイトルの右に表示し、価格不明のものは「価格未登録」とします。購入合計は表示しません。難易度・学習日数・分野タグはアプリ側の編集情報であり、出版社の保証ではありません。

大学別の詳細な出題傾向・配点や、すべての資格試験を網羅しているわけではありません。大学入試は2027年度一般選抜の87大学・712学部等・2,228募集単位の科目表を事前収録しています。大学→試験日→学部・学科→入試方式→選択科目→ルートを作る教科の順で絞り込みます。共通テストと個別試験を分離します。入試科目の出典は河合塾Kei-Netで、入試得点・募集人数や長い解説文は収録しません。出願条件のすべてを判定する機能ではなく、複雑な科目の組み合わせは出願内容に合わせて選択します。未収録の大学・年度は受験科目を自分で選び、未確認の年度に別年度の科目を自動適用しません。法律関連の資格は受験年度に対応する版の確認が必要です。未照合・旧課程の教材は提案から外します。

選んだルートは既存のアカウント別ローカル保存と非公開クラウド同期の対象です。プラン設定と週間プランの質問画面から参照できます。学習時間ランキングは「学習記録」内にあります。

書影は [openBD利用規約](https://openbd.jp/terms/) の本の紹介目的の利用権に基づき、`python scripts/collect-book-covers.py` で取得します。ISBN・書名を照合した提供画像を無加工で保存し、`assets/book-covers.json` に取得元・規約・ハッシュ・確認日・有効期限を記録します。週1回以上再収集してください。表示時にも公開APIで削除・変更を確認し、キャッシュは7日で失効します。削除要請は `assets/book-cover-denylist.json` にISBNを登録して再収集・再公開すると、画像ファイルと表示を取り除けます。許諾・一致を確認できない本、画像の取得失敗時はオリジナルの本のイラストを表示します。検索サイトや販売サイトからの無断転載は行いません。TACの書影は `python scripts/collect-tac-covers.py` で、公式の[紹介利用条件](https://www.tac-school.co.jp/copyright/permission.html)を確認したうえで取得します。公式ストアの公開商品ページとISBN・書名を照合し、表紙の横に正確な公式商品リンクを表示します。紹介条件をSNSへの本文・教材投稿へ流用しません。両収集スクリプトは週1回以上再実行し、再公開してください。openBDの再収集は有効なTACのキャッシュを保持します。提供元別の公開条件の調査は [確認記録](docs/book-cover-rights-review.md) を参照してください。元の `api/book-cover.js` もサーバー環境用に残しています。

書誌更新：`python scripts/refresh-book-catalog.py` の後に `python scripts/enrich-book-catalog.py`。AIやAPIキーは不要です。NDLの応答を `work/ndl-cache/` にキャッシュし、失敗・未照合は提案対象外のまま保持します。収集後は版・分野・難易度を編集レビューしてください。シリーズの追加取り込みは `scripts/import-junior-books.py` と `scripts/import-confirmed-series.py` を使用し、その後に補助タグの付与とカタログテストを実行します。出典：[NDL Search API](https://ndlsearch.ndl.go.jp/help/api)。カタログを更新するときは既存のIDを維持してください。

検証：`node tests/book-route-questions.cjs`、`node tests/book-catalog.cjs`、`node tests/book-route-engine.cjs`、`node tests/book-routes-api.cjs`、`node tests/book-routes.browser.cjs`。ブラウザテストにはPlaywrightとChromiumが必要です。ルート選定、所持教材、時間配分がないこと、未対応試験、保存とアカウント分離、AI通信がないことを検証します。

作成画面：参考書ルートのページは保存済みルートの一覧です。右上の「参考書ルートを作る」で全画面の作成フローを開き、作成完了アニメーションから候補を表示します。保存すると一覧へ戻ります。動きを減らす設定にも対応します。教材カードは「」付きタイトル、価格、簡潔な特徴、出版社・版・書籍情報で構成し、設定内容や長い説明・注意文・進め方・登録分野は表示しません。

質問の分岐：数学は単元選択を省略し、教科全体の実力と目標を選びます。単元選択は英語・国語や複数の対象分野を持つ資格で表示します。入試の目標得点率は10%〜90%以上を選べます。登録済みの難関大学では、低い得点率を選んでも目標得点率だけで教材を初歩レベルに限定せず、現在の実力と試験の難易度を考慮します。

一括収録：`python scripts/collect-comprehensive-catalog.py`、`python scripts/collect-catalog-supplement.py`、`python scripts/finalize-book-collection.py` の順で取得・統合します。NDL SRUは501件目以降を返さないため、出版日を明示した互いに重ならない期間に分割し、各区間を500件以下に収めます。4ワーカー、全体で2秒以上のリクエスト間隔、永続キャッシュ・再試行を使います。失敗区間が残る場合は統合しません。`python scripts/expand-book-catalog.py --write --cached-only` でも取得済み主要データから再構築できます。難易度・分野タグは書誌とは別の編集情報です。一次応答とマニフェストは `work/catalog-bulk/`、公開可能な集計・検索条件は `assets/book-collection-report.json` と `assets/book-collection-sources.json` に保存します。

版の扱い：出版社＋主要書名＋巻・レベルを基準に、年度表記や改訂表示を取り除いて同じ教材の重複を除きます。巻や試験の級が異なるものは別の教材です。ISBNのチェックディジットも検証します。大学別教材は対応大学で絞り、教科書準拠教材は所持しているものだけをルートに含めます。書誌確認と内容の評価は別で、難易度・分野の分類はアプリの編集情報です。

入試科目データ：`assets/university-admissions.json`。`python scripts/collect-university-admissions.py` は既存大学の科目表を1大学1ページずつ取得し、`work/admissions` にキャッシュします。収集時のみbeautifulsoup4が必要です。`node tests/book-route-admissions.cjs` で学部・学科・方式・選択科目・年度分岐と保存する条件を検証します。

所持教材の検索：書名・出版社を空白区切りで検索し、対象の試験・教科内だけで絞り込みます。検索語の変更・クリア後も選択済み教材を保持します。候補が多いときは30件ずつ表示し、検索語を入力する前に全教材は並べません。

知名度・版の扱い：`assets/book-route-policy.js` の出典付き定番シリーズ表を、適合度・所持教材の優先度が同じ場合の順位付けに使用します。書店売上や知名度の実測値を作らず、出版社名だけでは加点しません。年度を明示した教材は現在年以降に限定し、収録済みの同じ教材に新しい年度版・改訂版があれば古い版を提案しません。年度のない現行のロングセラーを発行年だけで除外しません。所持教材の検索候補にも同じ版の制限を適用します。以前保存したルートは維持します。

範囲の不足を防ぐ処理：`assets/book-route-coverage.js` が、物理・化学では選ばれた各学習段階、国語ではルート全体の分野を確認します。分冊シリーズの必要な巻を補い、冊数の目安を理由に分野を削りません。全範囲を補える一冊でコンパクトに組む案も比較します。所持教材を尊重しつつ、未所持の重複教材を減らします。「熱」「原子」などのタグを収録処理でも抽出し、基礎科目のみの本や分野別の本を全範囲の教材として扱いません。単元を限定した条件では必要な範囲だけを補います。不足を補えない場合は、その不完全な候補を返しません。`node tests/book-route-coverage.cjs` で実カタログの実力・期間の組み合わせ、分冊、未収録、旧年度版を検証します。

週間プランの再作成：初回・期間終了後・設定からの立て直しは全画面の7問（目標、試験日、平日の時間、休日の時間、科目・教材、優先度、繰り越し）に統一します。前回の値を初期表示し、旧4ステップの条件画面は表示しません。新しい週では前の週の途中回答を流用せず、同じ週の「あとで」は尊重して再開できます。`node tests/weekly-replan.browser.cjs` で週終了、7問の完了、作り直し、記録・履歴・参考書ルートの保持を検証します。

教材台帳：`assets/book-registry.json` は年度・改訂版を統合した14,147教材、ISBNの異なる22,535版を保持します。登録済みの旧版も保持しますが、ルート提案とは別です。「収録教材を検索」から書名・出版社・ISBNで検索でき、各結果はNDLの原書誌へリンクします。現在販売中の完全網羅・在庫・販売価格を確認した一覧ではありません。未対応試験の教材は検索台帳で参照でき、質問画面には対応済み試験だけを出します。英検・TOEIC・TOEFLの旧形式や旧年度版を提案から除外し、新しい版を収録するときも既存教材IDと編集タグを保持します。
